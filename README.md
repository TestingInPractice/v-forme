# Тренажёр — Фитнес PWA

Персональный фитнес-тренажёр для iPhone с голосовым сопровождением на русском языке.

## Возможности

- **Авто-сборка тренировки**: по группе мышц, калориям или времени
- **Ручная сборка**: выбор упражнений с защитой от завышения повторений
- **Голосовой.runner**: таймер, голосовые подсказки на русском, приглушение музыки
- **Музыка**: импорт аудиофайлов через OPFS, воспроизведение оффлайн
- **История**: записи тренировок с календарём по датам
- **PWA**: устанавливается на iPhone, работает оффлайн

## Как запустить

```bash
cd /Users/halapinvv/Documents/fitness-app
python3 -m http.server 8000
```

Откройте `http://localhost:8000` на iPhone (в той же Wi-Fi сети) или в браузере.

Для установки на iPhone: Откройте в Safari → «Поделиться» → «На экран Домой».

## Технологии

- Ванильный HTML/CSS/JS, без фреймворков и сборщиков
- IndexedDB для данных (история, настройки)
- OPFS для хранения музыкальных файлов
- Service Worker для оффлайн-режима
- speechSynthesis API для голоса на русском
- Wake Lock API для блокировки экрана во время тренировки

## Структура

```
/
├── index.html              # Точка входа SPA
├── manifest.webmanifest    # PWA манифест
├── sw.js                   # Service Worker
├── icons/                  # SVG иконки
├── data/
│   └── exercises.js        # База упражнений (MET, группы мышц)
└── src/
    ├── css/style.css       # Стили (тёмная тема)
    └── js/
        ├── app.js          # Точка входа JS
        └── modules/
            ├── db.js        # IndexedDB обёртка
            ├── settings.js  # Настройки
            ├── music.js     # Музыка (OPFS)
            ├── workout.js   # Сборка тренировок
            ├── runner.js    # Голосовой runner
            ├── history.js   # История
            └── ui.js        # SPA роутер + экраны
```

## Экраны

1. **Главная** — навигация + CTA «Собрать тренировку»
2. **Сборка** — вкладки «Авто» / «Вручную»
3. **Музыка** — импорт, список, управление
4. **Настройки** — отдых, приглушение, голос, экран, вес
5. **История** — записи по датам
6. **Запуск** — большой таймер, фаза, прогресс, управление
